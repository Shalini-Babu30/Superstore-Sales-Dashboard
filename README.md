# Superstore-Sales-Dashboard
An interactive Power BI dashboard built to analyze sales performance, profit, customer segments, and regional business trends.

## 🚀 Features

- Interactive Power BI dashboard
- Sales analysis
- Profit analysis
- Customer segmentation
- Regional performance
- KPI visualization

---

## 🛠️ Tools Used

- Microsoft Power BI



## 📊 Dashboard Insights

- Total Sales
- Total Profit
- Sales by Region
- Sales by Category
- Monthly Sales Trend
- Top Products
